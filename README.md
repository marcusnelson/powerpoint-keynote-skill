# powerpoint-keynote-presentation skill

A Claude Code skill for creating and working with PowerPoint and Keynote presentations.

## What it does

This skill enables Claude Code to build, edit, and export slide decks in both `.pptx` (PowerPoint) and Keynote formats. It handles narrative deck scaffolding — structured slide layouts, section flows, and content templates — so you can go from a brief to a polished presentation without leaving your terminal.

## How to use

1. Download `powerpoint-keynote-presentation.skill`
2. In Claude Code, load the skill with:
   ```
   @"/path/to/powerpoint-keynote-presentation.skill"
   ```
3. Ask Claude to create or edit a presentation.

## Requirements

- [Claude Code](https://claude.ai/code)
